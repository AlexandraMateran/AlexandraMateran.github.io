Proyectos QA

01

Automatización de Pruebas Web — Urban Routes

Python · Selenium · pytest · Page Object Model · GitHub

Desafío

Automatizar el flujo completo de pedido de taxi en una aplicación web, cubriendo desde la selección de ruta hasta la confirmación del servicio.

Proceso

Implementé el patrón Page Object Model separando localizadores, métodos y pruebas. Usé 4+ tipos de localizadores (ID, XPATH, CLASS_NAME, NAME) con WebDriverWait para esperas dinámicas.

Resultado

8 pruebas automatizadas cubriendo el flujo completo. Proyecto publicado en GitHub con README y buenas prácticas de control de versiones.

Python Selenium pytest POM Git GitHub

02

Automatización de Pruebas de API — Urban Grocers

Python · pytest · requests · GitHub

Desafío

Validar el campo "name" en la creación de kits de productos mediante pruebas automatizadas que cubrieran escenarios positivos, negativos y valores límite.

Proceso

Diseñé funciones reutilizables (positive_assert, negative_assert_code_400) para evitar duplicación de código. Apliqué clases de equivalencia y análisis de valores límite.

Resultado

9 pruebas automatizadas. Identifiqué 4 bugs reales en la API relacionados con validaciones de longitud y tipo de dato. Proyecto publicado en GitHub.

Python pytest requests API Testing GitHub

03

Testing de API REST — Plataforma de Compras

Postman · Jira · JSON · Test Case Design

Desafío

Validar los endpoints de gestión de kits y servicios de entrega en una plataforma de compras, asegurando que la API respondiera correctamente a diferentes escenarios.

Proceso

Diseñé y ejecuté 30+ test cases en Postman, incluyendo escenarios positivos, negativos y edge cases. Validé requests/responses analizando estructuras JSON y códigos HTTP.

Resultado

Detecté errores en códigos HTTP (400, 404, 500), fallos en validaciones y problemas en lógica de negocio. Bugs documentados en Jira con pasos de reproducción y severidad.

Postman API Testing JSON Jira Test Case Design

04

Validación de Base de Datos & Análisis de Logs

SQL · PostgreSQL · Bash · Linux · SSH

Desafío

Validar la integridad de datos en una base de datos de taxis y analizar logs de servidor para identificar errores en producción.

Proceso

Ejecuté consultas SQL complejas (JOINs, GROUP BY, HAVING, CASE, CAST). Accedí a servidor remoto via SSH y analicé logs usando grep, cat y redirección de salida.

Resultado

Validé integridad de datos en múltiples tablas. Aislé errores 400 y 500 en archivos separados organizados por tipo de error para facilitar el debugging del equipo.

SQL PostgreSQL Bash Linux SSH
